# BlockFlow 定價策略 + 方案設計

---

## 核心挑戰：用戶自帶 API Key

BlockFlow 目前是「用戶自備 NVIDIA API Key」模式，這對收費設計有重大影響：

```
❌ 無法對 AI 聊天次數收費 → 用戶已經在付 NVIDIA 了
✅ 可以對「便利性」收費 → 不用自己申請 Key、更強模型、更多功能
✅ 可以對「加值服務」收費 → 進階語音、雲端同步、數據分析
✅ 可以對「平台功能」收費 → 多裝置、推播通知、進階行事曆
```

### 解決方案：三層 API Key 策略

| 方案 | 誰付費 | 限制 | 適合對象 |
|------|--------|------|---------|
| **用戶自帶 Key** | 用戶付 NVIDIA | 只能用 Llama 3.1 8B（標準模型） | 技術用戶、開發者 |
| **Pro 內含 Key** | 我們付 NVIDIA，用戶付月費 | 可用所有模型（含 Nemotron Super 49B） | 一般用戶、學生 |
| **BYOK + 加購** | 用戶自備 Key + 付月費 | 進階功能（語音、同步、分析） | 想省錢的進階用戶 |

```
  Free   → $0
  學生   → $2.99/月 或 $29/年

為什麼這樣定？
  ┌─────────────────────────────────────┐
  │ Motion $34/mo → 太貴，目標是企業   │
  │ Akiflow $29/mo → Mac only，太貴    │
  │ Reclaim $15/mo → 團隊為主          │

  │ → 比 Reclaim 便宜 3 倍             │
  │ → 比 Motion 便宜 7 倍              │
  │ → 台灣學生 $90/月 = 一杯手搖飲     │
  └─────────────────────────────────────┘
```

## 收費模型比較

| 模型 | 適合 BlockFlow？ | 原因 |
|------|----------------|------|
| **月訂閱** | ✅ 主力 | 持續收入，用戶習慣穩定 |
| **年訂閱** | ✅ 鼓勵 | 一次性收入大，留存率高 |
| **終身買斷** | ⚠️ 可考慮 | 初期募資可用，但長期不推 |
| **用量計費** | ❌ 不適合 | 用戶自備 Key，無法計量 |
| **廣告** | ❌ 違背產品哲學 | 產品定位是乾淨體驗 |
| **Sponsor / 贊助** | ⚠️ 可作為補充 | GitHub Sponsor、Open Collective |

### 關於終身方案

```
建議在以下時機推出：
  ✅ 正式上架 App Store / Product Hunt 時
  ✅ 限時限量（前 1000 位用戶 $99）
  ❌ 不作為常態方案

因為 PWA 持續迭代有成本，
終身方案會讓收入模型不健康。
```

## 預估收入模型

假設條件（保守估計）：
- 月活躍用戶（MAU）：10,000
- Free → Pro 轉換率：3%（業界平均 Freemium 轉換率 2-5%）
- 學生佔 Pro 用戶：40%
- 年訂閱佔比：30%

```
收入試算（月）：

  Pro 用戶：10,000 × 3% × 60% = 180 人
  180 × $4.99 = $898/月

  學生用戶：10,000 × 3% × 40% = 120 人
  120 × $2.99 = $359/月

  年訂閱加成（30% 用戶選年繳）：
  (180 + 120) × 30% = 90 人
  90 × ($49 - $60) ≈ -$0.83/人/月
  （年繳有折扣但一次收入）

  MRR ≈ $1,257/月 ≈ NT$40,000/月

  若 MAU 擴大到 50,000：
  MRR ≈ $6,285/月 ≈ NT$200,000/月
```

## 倫理底線：永遠免費

以下功能**永不收費**，這是產品核心價值：

```
✅ 三區塊規劃（Focus / Personal / Recovery）
✅ Pomodoro 計時器
✅ 基本行事曆（月檢視 + 基本 CRUD）
✅ 瀏覽器語音輸入/輸出
✅ 無廣告（永遠）
✅ 本機資料完整可用（不綁雲端）
```

> 用戶的資料永遠屬於用戶，即使不付費，也可以完整使用所有本機功能。
