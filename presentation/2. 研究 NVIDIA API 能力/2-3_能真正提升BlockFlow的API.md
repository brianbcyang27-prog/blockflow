# 哪些 API 能真正提升 BlockFlow

## 核心理念

不是為了「用 AI 而用 AI」，而是**每一項能力都要對應一個學生的真實痛點**。

---

## 📖 Read ＋ 🧠 Think → AI 三區塊排程

**學生痛點**：每天花 10 分鐘決定「今天要怎麼安排」

**目前的 BlockFlow**：手動拖曳區塊 + 基本 local heuristic

**升級方案**：讓 AI 同時做到「閱讀你的需求」和「思考最佳安排」

```
你輸入：「明天早上9點上課到12點，下午要寫程式作業，晚上7點要去健身房」

🧠 Nemotron Nano 9B v2 自動產出：
┌─────────────────────────────────────────┐
│   Focus    │   Personal   │  Recovery   │
│ 09:00-12:00│ 14:00-17:00  │ 21:00-22:00 │
│  上課      │  寫程式作業   │  休息放鬆   │
│            │  ⚡ 建議安排在專注高峰時段  │
└─────────────────────────────────────────┘

💡 還會根據你的歷史數據補充：
「你週二下午效率最高，建議把困難作業排在這時段」
```

| 項目 | 評估 |
|---|---|
| 使用能力 | 📖 Read（理解需求）+ 🧠 Think（規劃排程） |
| 使用模型 | Nemotron Nano 9B v2 |
| 開發難度 | 🟢 中等 — 已有 AI Assistant 基礎架構 |
| 市場價值 | ⭐⭐⭐⭐⭐ — 這是 BlockFlow 的核心價值 |

---

## 👁️ See → 講義/課本智能掃描

**學生痛點**：老師講義太亂，找不到重點

**目前的 BlockFlow**：無此功能

**升級方案**：拍照即理解

```
📱 學生打開 BlockFlow → 拍下課本頁面

👁️ Phi-4 Multimodal 或 Nemotron 3 Nano Omni：
┌─────────────────────────────────────────┐
│  📖 第三章：機器學習概論                │
│  🔑 重點概念：                          │
│    • 監督式學習 — 有標籤資料訓練        │
│    • 分類問題 — 離散輸出                │
│    • 迴歸問題 — 連續輸出                │
│  📝 摘要：本章介紹監督式學習的兩個主要   │
│    任務：分類與迴歸...                   │
│  ✅ 待辦：完成課後習題 1-5 題           │
└─────────────────────────────────────────┘
```

| 項目 | 評估 |
|---|---|
| 使用能力 | 👁️ See（圖片理解）+ 📖 Read（摘要） |
| 使用模型 | Phi-4 Multimodal 或 Nemotron 3 Nano Omni |
| 開發難度 | 🟡 中高 — 需處理圖片壓縮、多頁掃描 |
| 市場價值 | ⭐⭐⭐⭐⭐ — 學生的第二大痛點，App Store 賣點 |

---

## 👂 Listen → 語音建立行事曆

**學生痛點**：打字好麻煩，用說的比較快

**目前的 BlockFlow**：Nova STT 已可語音輸入，但未整合行事曆

**升級方案**：用說的建立區塊

```
🎤 學生對著手機說：
「明天早上九點上課，下午兩點到五點寫報告，晚上去健身房」

👂 Browser STT + 🧠 Nemotron Nano 9B v2：
┌─────────────────────────────────────────┐
│  ✅ Focus 09:00-12:00 → 上課            │
│  ✅ Focus 14:00-17:00 → 寫報告          │
│  ✅ Personal 19:00-20:30 → 健身房       │
│  「要幫你加入行事曆嗎？」               │
└─────────────────────────────────────────┘
```

| 項目 | 評估 |
|---|---|
| 使用能力 | 👂 Listen（語音辨識）+ 🧠 Think（語意解析） |
| 使用模型 | Browser STT（免費）+ Nemotron Nano 9B v2 |
| 開發難度 | 🟢 低 — 已有 Nova STT + NL Scheduling |
| 市場價值 | ⭐⭐⭐ — 提升輸入效率 |

---

## 🗣️ Speak → AI 語音助理

**學生痛點**：不想一直看著螢幕

**目前的 BlockFlow**：Nova TTS 已可朗讀文字

**升級方案**：讓 AI 主動「說」給你聽

```
🔊 情境一：計時器結束
「Focus 區塊結束了！要不要休息 5 分鐘？
   你今天的專注時間已經達到 3 小時，表現不錯！」

🔊 情境二：每天早晨
「早安！你今天有 3 個 Focus 區塊。
   第一堂課在 9 點，建議你先準備一下。」
```

| 項目 | 評估 |
|---|---|
| 使用能力 | 🗣️ Speak（語音合成）+ 🧠 Think（決策） |
| 使用模型 | Kokoro TTS（免費本地）/ ElevenLabs（高品質） |
| 開發難度 | 🟢 低 — 已有 Nova TTS 基礎 |
| 市場價值 | ⭐⭐⭐ — 提升無障礙體驗與便利性 |

---

## 💾 Remember → 筆記語意搜尋

**學生痛點**：「我記得有記過這個重點，但找不到在哪」

**目前的 BlockFlow**：只能手動翻歷史紀錄

**升級方案**：自然語言搜尋所有筆記

```
🔍 學生搜尋：「gradient descent 的學習率怎麼設」

💾 NeMo Retriever Embeddings 找出：
┌─────────────────────────────────────────┐
│  📅 上週二 機器學習課堂筆記             │
│  「學習率（learning rate）控制每次更新   │
│    的步伐大小，太大會震盪，太小收斂慢」 │
│  相關度：97%                            │
│                                         │
│  📅 昨天 作業筆記                       │
│  「adam optimizer 的自適應學習率...」   │
│  相關度：82%                            │
└─────────────────────────────────────────┘
```

| 項目 | 評估 |
|---|---|
| 使用能力 | 💾 Remember（語意檢索） |
| 使用模型 | NeMo Retriever Embeddings + Rerank |
| 開發難度 | 🟡 中 — 需向量資料庫與嵌入管線 |
| 市場價值 | ⭐⭐⭐ — 解決「找不到」的痛點 |

---

## 🧠 Think → 每週 AI 教練報告

**學生痛點**：「我這週過得怎麼樣？哪裡可以改進？」

**目前的 BlockFlow**：基本圖表，無 AI 分析

**升級方案**：AI 分析一週數據，給出具體建議

```
📊 你這週 Focus 時間佔比 42%，比上週下降 15%

🔍 AI 分析發現：
  • 你週二下午最容易分心（3 次紀錄）
  • 你週五早上效率最高（2.5hr 連續專注）

💡 建議：
  1. 把困難任務排在週五早上
  2. 週二下午安排 Recovery 區塊
  3. 你這週 Recovery 時間充足（8.5hr），值得保持！
```

| 項目 | 評估 |
|---|---|
| 使用能力 | 🧠 Think（數據分析 + 建議產出） |
| 使用模型 | Nemotron Nano 9B v2 |
| 開發難度 | 🟢 低 — 已有數據收集基礎 |
| 市場價值 | ⭐⭐⭐ — 從「工具」升級為「教練」 |

---

## 總結：產品升級路線圖

```
v4.1（現在）
  核心：三區塊手動排程 + 基本 AI 聊天

v4.2（2 週）
  AI 三區塊排程（🧠 Think）
  每週 AI 教練報告（🧠 Think）

v4.3（1 個月）
  講義智能掃描（👁️ See + 📖 Read）
  語音建立行事曆（👂 Listen + 🧠 Think）

v5.0（2 個月）
  AI 語音助理（🗣️ Speak + 🧠 Think）
  筆記語意搜尋（💾 Remember）
```

**一句話總結：BlockFlow 正從「手動排程工具」進化為「看得見、聽得懂、會思考、能提醒的全方位 AI 學習助手」。**
