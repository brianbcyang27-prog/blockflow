02 · Top Models

最具潛力的模型排名

#1

🧠 Nemotron Nano 9B v2

AI 大腦升級，讓 BlockFlow 真正會「思考」
可控推理深度（Reasoning Budget Control）— 開關切換推理模式
128K 上下文視窗 — 可一次讀完整週行程
關鍵價值：取代 Llama 3.1 8B 成為預設模型，排程從規則比對進化為真正理解
#2

🧠+👁️+👂 Nemotron 3 Nano Omni 30B

AI 全能模態，看影片、聽錄音、讀講義全部一台搞定
MoE 架構（30B 參數，每次只啟動 3B）— 高效又強大
影片理解 → 音訊理解 → 圖片 OCR → 文字推理
關鍵價值：一個模型取代五個功能，從文字助理進化為全方位學習助手
#3

👁️ Phi-4 Multimodal Instruct

輕量級多模態，適合頻繁使用的情境
微軟出品，品質穩定
同時支援文字 + 圖片 + 音訊
關鍵價值：比 Omni 更輕量，適合手機端頻繁呼叫，拍照課本即時摘要
#4

💾 NeMo Retriever Embeddings + Rerank

讓 AI 擁有「記憶」，找到你曾經記下的任何東西
語意搜尋（不是關鍵字比對）
Embeddings + Rerank 雙層架構 → 精準度業界頂尖
關鍵價值：解決學生「記得有記過但找不到」的永恆痛點

能真正提升 BlockFlow 的 API 功能

每一項能力都對應一個學生的真實痛點

📖 + 🧠 AI 三區塊排程

🎯 學生痛點：每天花 10 分鐘決定「今天要怎麼安排」
「明天早上9點上課到12點，下午要寫程式作業，晚上7點要去健身房」
→ AI 自動產出三區塊排程，含個人化建議
🧠 Nemotron Nano 9B v2 🟢 開發難度：中 ⭐⭐⭐⭐⭐ 市場價值

🎯 學生痛點：老師講義太亂，找不到重點
📱 學生打開 BlockFlow → 拍下課本頁面 → AI 提取重點概念 + 摘要 + 待辦建議
👁️ Phi-4 / Omni 🟡 開發難度：中高 ⭐⭐⭐⭐⭐ 市場價值

👂 語音建立行事曆

🎯 學生痛點：打字好麻煩，用說的比較快
🎤 「明天早上九點上課，下午兩點到五點寫報告」
→ 自動辨識並加入對應區塊
👂 Browser STT + 🧠 Nano 9B 🟢 開發難度：低 ⭐⭐⭐ 市場價值

🗣️ AI 語音助理

🎯 學生痛點：不想一直看著螢幕
