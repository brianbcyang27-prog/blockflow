# 最具潛力的模型 — 以能力分類

---

## 🧠 Think — Nemotron Nano 9B v2（第一名）

**一句話：AI 大腦升級，讓 BlockFlow 真正會「思考」**

### 為什麼最強？
```
可控推理深度（Reasoning Budget Control）
  ├── 開 → 深度推理：品質極高，適合複雜排程
  └── 關 → 快速回應：延遲極低，適合日常對話

128K 上下文視窗 = 可一次讀完整週行程 + 使用者習慣
```

### 對產品的影響
- **取代 Llama 3.1 8B** 成為預設模型
- 排程建議從「規則比對」進化為「真正理解」
- 可根據歷史數據產生個人化建議

---

## 🧠+👁️+👂 — Nemotron 3 Nano Omni 30B（第二名）

**一句話：AI 全能模態，看影片、聽錄音、讀講義全部一台搞定**

### 為什麼最強？
```
MoE 架構（30B 參數，每次只啟動 3B）
  ├── 影片理解 → 課程錄影自動轉筆記
  ├── 音訊理解 → 語音備忘錄轉行事曆
  ├── 圖片 OCR  → 講義掃描提取重點
  └── 文字推理 → 串聯所有資訊產出摘要

2026 年 4 月最新發布，代表 NVIDIA 當前最高水準
```

### 對產品的影響
- **一個模型取代五個功能**：OCR + 轉錄 + 摘要 + 分析 + 對話
- 讓 BlockFlow 從「文字助理」進化為「全方位學習助手」

---

## 👁️ — Phi-4 Multimodal Instruct（第三名）

**一句話：輕量級多模態，適合頻繁使用的情境**

### 為什麼有潛力？
```
微軟出品，品質穩定
同時支援：文字 + 圖片 + 音訊
比 Omni 更輕量 → 適合手機端頻繁呼叫
```

### 對產品的影響
- 拍照課本 → 即時摘要（適合學生在上課時使用）
- 圖表/表格分析 → 提取考試重點
- **比 Omni 更適合行動裝置**

---

## 💾 — NeMo Retriever Embeddings + Rerank（第四名）

**一句話：讓 AI 擁有「記憶」，找到你曾經記下的任何東西**

### 為什麼有潛力？
```
語意搜尋（不是關鍵字比對）
  ├── 「找到我上禮拜關於機器學習的筆記」
  └── 「gradient descent 還有在哪裡出現過？」

Embeddings + Rerank 雙層架構 → 精準度業界頂尖
```

### 對產品的影響
- 讓 100+ 筆筆記變得可搜尋
- 跨時間、跨課程的知識連結
- **解決學生「我記得有記過但找不到」的永恆痛點**

---

## 🗣️👂 — Nova 語音系統（已整合）

**一句話：讓使用者用「說的」比用「打的」更快**

### 現有能力
| 功能 | 技術 | 狀態 |
|---|---|---|
| 語音輸入（聽） | Browser STT + 可擴充 Provider | ✅ 已上線 |
| 語音輸出（說） | Browser TTS + Kokoro + tts.ai + ElevenLabs | ✅ 已上線 |
| 語音波形動畫 | Canvas 自訂繪製 | ✅ 已上線 |
| 語者複製 | MediaRecorder 錄音（實驗性） | 🔧 實驗中 |

### 潛力延伸
- 語音建立行事曆：「明天早上九點加一堂課」
- 語音查詢筆記：「我上次關於 gradient descent 的筆記在哪？」
- **整合 Nemotron Omni** → 從單純 TTS/STT 升級為「語音 AI 助理」

## 🧠 — cuOpt（觀察清單）

**一句話：理論上可以最佳化課表，但需要更多驗證**

```
約束求解引擎
  ├── 可考慮：時間衝突、精力分配、優先級
  └── 但文獻主要為物流/派遣設計

結論：潛力存在，但學生場景需客製化
      ⏳ 列為中長期觀察項目
```
